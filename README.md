# Discord 통합 관리 봇 V3

## 기능

### `/채널생성`
지정한 이름, 종류, 카테고리로 채널 생성.

예:
`/채널생성 이름:공지사항 종류:텍스트 카테고리:정보`

종류:
- 텍스트
- 음성

### `/에브핑`
`@everyone`을 멘션하고 지정한 메시지를 전송.

예:
`/에브핑 메시지:오늘 8시에 점검합니다.`

관리자만 사용 가능.

### `/리마인더`
지정한 간격마다 현재 채널에 메시지를 반복 전송.

예:
`/리마인더 메시지:출석 체크하세요 간격:1 단위:일`

지원 단위:
- 분
- 시간
- 일

리마인더는 `reminders.json`에 저장되므로 봇이 재시작되어도 유지됨.

추가 명령:
- `/리마인더목록`
- `/리마인더삭제`

### `/고스트메시지`
메시지를 전송한 뒤 즉시 삭제하는 것을 반복.

예:
`/고스트메시지 메시지:잡아봐라 횟수:10 간격:1`

횟수는 최대 20회로 제한.

### `/디엠`
서버의 지정한 멤버에게 DM 전송.

예:
`/디엠 사용자:@홍길동 메시지:공지사항 확인해줘`

## 설치

```bash
pip install -r requirements.txt
python bot.py
```

## config.json

```json
{
    "token": "디스코드 봇 토큰"
}
```

## 봇 권한

- View Channels
- Send Messages
- Read Message History
- Manage Channels
- Mention Everyone
- Manage Messages (필요한 경우)

DM 기능은 상대방이 봇의 DM을 허용한 경우에만 작동한다.
